## 📱 Responsive Breakpoints

```
Mobile (320px - 640px)
├─ Single column layout
├─ Stacked components
├─ Hamburger mobile menu
└─ Touch-friendly sizes

Tablet (641px - 1024px)
├─ Two column layouts
├─ Optimized spacing
├─ Desktop menu appears
└─ Larger text

Desktop (1025px+)
├─ Full multi-column layouts
├─ Maximum readability
├─ All animations active
└─ Premium spacing
```

## 🎭 Animation Effects

```
ON PAGE LOAD:
├─ Hero section fades in
├─ Portrait animates with magnet effect
├─ Text slides up with fade
├─ Buttons appear with stagger
└─ Scroll indicator bounces

ON SCROLL:
├─ Sections fade in from below
├─ Cards slide up smoothly
├─ Icons scale up on entry
├─ Text animates character by character
└─ Numbers count up

ON HOVER:
├─ Buttons scale and glow
├─ Cards lift and shadow deepen
├─ Icons scale up
├─ Links change color
└─ Text highlights appear

ON MOBILE:
├─ Menu slides from top
├─ Touch optimized interactions
├─ Reduced motion available
└─ Smooth tap feedback
```
