## 💡 Customization Tips

### Change Colors
Edit `src/index.css` to update the color theme:
```css
@theme {
  --color-dark-bg: #0C0C0C;
  --color-light-text: #D7E2EA;
}
```

### Update Content
All section content is easily editable in:
- `src/sections/*.tsx` - All section files
- Direct text replacement for quick updates

### Add Social Links
Update contact methods in `src/sections/ContactSection.tsx`
